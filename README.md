# Orb One Client React

React, TypeScript, Zustand, TanStack Router, TanStack Query, and shadcn/ui based frontend.

## Setup

```bash
pnpm install
pnpm dev
```

## Quality Gates

All contributors should run the same checks before opening a PR:

```bash
pnpm typecheck
pnpm lint
pnpm format:check
pnpm test
pnpm build
```

For convenience, the combined command is:

```bash
pnpm check
```

## Formatting And Linting

This project uses Prettier for formatting and ESLint for code quality. VS Code users get recommended extensions and format-on-save settings from `.vscode/`.

Useful commands:

```bash
pnpm format
pnpm lint
```

Git hooks run `lint-staged` before commits, so staged files are automatically linted and formatted. CI still runs the full checks, so hooks are a convenience rather than the source of truth.

## Project Structure

```txt
  app/          app-level providers and composition
  components/   shared UI components
  lib/          framework-agnostic utilities and API helpers
  routes/       TanStack Router file routes
  stores/       Zustand client-state stores
  test/         test setup and test utilities
```

## Environment Variables

Copy `.env.example` when creating local environment files.

```bash
cp .env.example .env.local
```

Only variables prefixed with `VITE_` are exposed to browser code.

## API Layer

Use `src/lib/api/client.ts` for shared request behavior such as base URL handling and JSON parsing. Feature code should build query functions on top of this client instead of calling `fetch` directly in components.

The shared client accepts paths with or without a leading slash:

```ts
apiClient('/users')
apiClient('users')
```

Successful JSON responses are parsed as JSON, empty responses return `undefined`, and non-JSON responses return text. Failed responses throw `ApiError` with the status, original `Response`, and parsed response body.

## Generated Files

`src/routeTree.gen.ts` is generated by TanStack Router and should be committed. Do not edit it manually; update route files under `src/routes/` and let the router plugin regenerate the file during development or build.
